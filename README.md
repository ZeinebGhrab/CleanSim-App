# 🧼 CleanSim-App – AI-Powered Cleaning Simulation System

**CleanSim-App** is a versatile system featuring an AI agent that manages cleaning tasks in a simulated environment. With a web interface and backend API, it allows users to observe and interact with the agent as it perceives its surroundings and reacts to maintain cleanliness.

---

## 🌐 About

CleanSim-App demonstrates a **reactive AI agent** operating in a virtual space. The agent perceives the current state of its environment and performs cleaning actions accordingly. Users can interact with the simulation through a user-friendly web interface, triggering actions or observing autonomous behaviors.

---

## 🔹 Key Features

- 🧠 **AI Agent** that follows a perception–action loop to maintain a clean environment  
- 🌍 **Simulated Environment** with dynamically changing dirt levels  
- 🖥️ **Web Interface** for real-time visualization and interaction  
- 🔄 **Reactive Logic**: the agent constantly updates its decisions based on environment feedback  
- 📊 Status display of the environment and agent activity  

---

## 🛠️ Technologies Used

- **Frontend**: React, TypeScript  
- **Backend**: Python, Flask  
- **AI Agent Logic**: Reactive model (Perception + Reaction)  
- **Simulation**: Custom environment with grid-based or dynamic representation
